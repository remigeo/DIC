"평균요율로 빈 칸 채우기"를 누르면 (주)드림인터내셔널코퍼레이션과 톡스메틱 두 열만 대상으로, 두 값이 모두 있는 제품들의 평균 비율을 구해 둘 중 하나만 비어있는 칸을 채웁니다. 두 값이 모두 비어있어 비교할 기준이 없는 제품은, 다른 제품들의 원가 대비 평균 요율을 이 제품의 원가에 적용해 대신 추정합니다(원가마저 없으면 건너뜁니다). 다른 거래처 열은 전혀 변경하지 않습니다. 자동으로 채워진 값은 파란색으로 표시되며, 직접 수정하면 다시 검정색으로 바뀝니다.

거래내역을 기준으로 기간을 선택해 매출과 이익을 집계합니다. 매출 = 공급가(VAT 포함) × 수량 + 배송비, 매입원가 = 제품 등록 화면의 원가 × 수량, 매입가(드림인터내셔널(공급가)+배송비) = 거래 등록 당시 고정된 매입가 × 수량 + 배송비(매입내역서 표의 합계와 같은 기준)입니다. 이익은 두 단계로 나눠 계산합니다: 디올수익 = (거래 등록 당시 고정된 매입가 − 제품원가) × 수량, 드림인터내셔널수익 = (거래 공급가 − 거래 등록 당시 고정된 매입가) × 수량 + 배송비 (단, 발주처가 (주)드림인터내셔널코퍼레이션 본인인 거래는 디올→드림인터내셔널 공급 거래로 보아 전액 디올수익으로 계산합니다. 매입가가 입력되지 않은 드문 거래만 [판매가·공급가·수익 관리]의 지금 등록값으로 대체합니다). 합계이익 = 디올수익 + 드림인터내셔널수익. 아래 그래프 표시에는 인터넷 연결이 필요합니다.

매입내역서

위에서 선택한 기간(및 발주처·공급사·월 필터)에 해당하는 거래를, "주식회사 디올 → (주)드림인터내셔널코퍼레이션" 매입 흐름으로 건별로 나열합니다. 공급자(매입처)는 항상 "주식회사 디올", 공급받는자는 항상 "(주)드림인터내셔널코퍼레이션"으로 표시되며, 납품처는 각 거래의 발주처(거래처)입니다. 매입가는 거래 등록 당시 고정된 값이며, 합계 금액도 이 기준입니다.
이 표(및 매출내역서)의 매입가는 모두 "거래 등록 당시" 고정된 값입니다. [판매가·공급가·수익 관리]에서 그 이후 (주)드림인터내셔널코퍼레이션 공급가를 수정한 제품이 있으면, 지금 등록된 값과 달라진 거래를 아래에서 ⚠로 표시·필터링할 수 있습니다.

매출내역서

위에서 선택한 기간(및 발주처·공급사·월 필터)에 해당하는 거래를, "(주)드림인터내셔널코퍼레이션 → 거래처" 매출 흐름으로 건별로 나열합니다. 발주처는 거래처, 공급사는 (주)드림인터내셔널코퍼레이션입니다. 수량·공급가(VAT포함)·매입가·배송비를 함께 보여주고 하단에 각 항목의 합계를 표시하며, 합계 금액은 공급가(VAT포함) 기준입니다.

1단계 · 발주서 파일 업로드

엑셀(.xlsx/.xls), CSV, 또는 PDF 발주서를 업로드하세요. 여러 파일을 한 번에 선택하면(Ctrl/Cmd 클릭 또는 Shift 클릭) 모두 같은 표 형식이라고 가정하고 첫 번째 파일의 머리글을 기준으로 하나의 표로 합쳐서 보여줍니다 — 파일마다 표 형식이 다르면 2단계에서 열 매칭이 어긋날 수 있으니 꼭 확인해주세요(이 경우 파일을 하나씩 올리는 것을 권장합니다). 시트가 여러 개인 엑셀 파일은 파일을 하나만 선택했을 때 "시트 선택"에서 실제 데이터가 있는 시트를 고를 수 있습니다(여러 파일을 한 번에 올릴 때는 각 파일의 첫 번째 시트를 사용합니다). PDF는 표 안의 글자 좌표를 분석해 행/열로 재구성하므로, 스캔 이미지(글자를 선택할 수 없는 PDF)는 인식할 수 없고 표 구조가 복잡하면 열이 어긋날 수 있습니다 — 업로드 후 2단계 미리보기에서 열 매칭을 꼭 확인해주세요. 열 매칭 → 신규 거래처 확인 → 제품명 비교 확인 절차를 거쳐 거래내역으로 등록합니다. (인터넷 연결이 필요합니다)

2단계 · 열 매칭

발주서의 각 열이 어떤 항목에 해당하는지 선택하세요. 자동으로 추측된 값이 미리 선택되어 있습니다.

3단계 · 신규 거래처 확인

발주서에 등장한 발주처 중 아직 등록되지 않은 거래처입니다. 체크된 항목은 등록 시 거래처로 자동 추가됩니다.

4단계 · 제품 매칭 확인

발주서의 제품명을 기존 등록 제품과 자동으로 비교했습니다. 일치하지 않으면 직접 선택하거나 "신규 제품으로 추가"를 선택하세요. 확인 후 등록 버튼을 눌러야 거래내역에 반영됩니다.
체크박스로 필요없는 행(합계/주소 등 잘못 인식된 행)을 여러 개 선택한 뒤 한 번에 지울 수 있습니다.

5단계 · 파일별 합계 확인

파일별 거래건수·매입가·공급가 합계를 원본 발주서 파일에 적힌 합계와 눈으로 대조해, 열 인식이 정확했는지 등록 전 마지막으로 확인하세요.
